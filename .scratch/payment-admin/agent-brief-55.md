## Agent Brief

**Category:** bug
**Summary:** admin payment BFF 的 wire 镜像 DTO / 北向 Response / 北向 Query 与 payment 真实契约对齐——金额 Long（分）、lifecycle 语义形状与信封、status-distribution 嵌套 refundBacklog、删 ghost 字段。决策已定稿 [ADR-0011](../blob/develop/docs/adr/0011-bff-amount-long-cents-and-verbatim-provider-mirror.md)，原则：**逐字镜像 provider 源码（`aieducenter-payment` 仓 `application/dto/response|query/*.java`），零加戏**。

**Current behavior:**
- **lifecycle 完全坏**：admin wire 预期 `(orderNo, events)` 包装信封 + 平表 union 事件（`logType`/`returnCode`/`targetType` 等 18 字段）；payment 实返 `ApiResponse<List<OrderLifecycleResponse>>` **扁平事件数组**（无 orderNo），事件为语义 9 字段 `(id, source, createdAt, action, actionName, outcome, performer, performerSystem, detail)`，`source` token 值为 `GATEWAY`/`OPERATION`。typeres 按包装 record 反序列化数组 → Jackson `MismatchedInputException`，**每次调用运行时报错**。
- **金额类型撒谎**：订单/退款/全部 stats 的 wire + 北向 Response + 北向 Query 金额字段全为 `BigDecimal`；payment 实为 `Long`（分）。值上常能跑通（Jackson 宽松反序列化掩盖），但类型不诚实且北向 Query javadoc 错称"以元承"（事实契约一直是分）。
- **status-distribution 活 bug**：admin 扁平 `refundPendingAuditCount`；payment 实为嵌套 `refundBacklog{ pendingCount, pendingAmount }`——字段名+嵌套双不符，今日恒 null，积压金额整个丢失。
- **refund ghost 字段**：admin 出口带 `auditorId`/`auditedAt`，payment 从不发送（恒 null）。

**Desired behavior:**
1. **lifecycle**：wire 镜像改为 `ApiResponse<List<事件>>` 信封 + 语义 9 字段事件 record；北向 Response 逐字镜像（含 `id`、`source` 的 `GATEWAY`/`OPERATION` token、全部语义字段）；`getLifecycle` 客户端方法与新信封对齐；北向 404 翻译行为保持不变。
2. **金额**：所有 payment 相关 wire / 北向 Response / 北向 Query 的**金额**字段 `BigDecimal → Long`（分）；**比率/均值字段**（`successRate`/`refundRate`/`approvalRate`/`avgAuditDurationMinutes`/`avgExecutionTimeMs`）保持 `BigDecimal`。Query 侧金额区间筛选同步 Long，javadoc 更正。**不做分↔元换算**（前端已按分提交）。
3. **status-distribution**：北向改为嵌套 `refundBacklog{ pendingCount, pendingAmount }` 镜像；分桶 `count`/`amount` 对齐 Long。
4. **refund ghost**：出口 wire + 北向删 `auditorId`/`auditedAt`；**北向 Query 的 `auditorId` 筛选保留**（payment `RefundOrderQuery` 支持）。
5. **契约测试**：新增 lifecycle 契约测试（真实信封：`ApiResponse` 包**扁平数组**，Long 字段 fixture 用 **string 形态** `"9900"`——框架全局 Long→`ToStringSerializer`，前端 `auditorId: string` 实证）；既有契约测试 fixture 的金额从 number 改 string 形态、backlog/ghost 字段按新形状更新。

**Key interfaces:**
- `OrderLifecycleWireResponse` 及其事件 record / 北向 `OrderLifecycleResponse` 及事件 / `PaymentClient.getLifecycle` 的 typeres——信封与形状重写（语义 9 字段）。
- payment 相关全部 wire record、北向 Response record、`PaymentOrderQuery`/`RefundOrderQuery`（北向）与对应 wire request——金额字段类型。
- `OrderStatusDistributionWireResponse` / 北向 `OrderStatusDistributionResponse`——嵌套 backlog。
- `RefundOrderWireResponse` 及北向退款 summary/detail——删 ghost。
- 应用层各 `toXxx` 静态映射方法随形状更新；北向 JSON 里 Long 字段变 string 属预期（ADR-0011），前端联动见 web issue。
