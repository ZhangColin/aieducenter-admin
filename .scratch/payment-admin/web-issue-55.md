admin BFF 后端正在做 wire DTO 与 payment 真实契约对齐（[ZhangColin/aieducenter-admin#55](https://github.com/ZhangColin/aieducenter-admin/issues/55)，决策见其 [ADR-0011](https://github.com/ZhangColin/aieducenter-admin/blob/develop/docs/adr/0011-bff-amount-long-cents-and-verbatim-provider-mirror.md)）。北向 JSON 形状有破坏性变更，需要 web 配合。**权威形状以 admin 仓 `*ContractTest` 钉住的为准**（分、string）。

## 变更点

1. **金额字段全部 `number → string`**：框架全局 `Long→JSON string` 序列化，金额改 `Long`（分）后北向出 `"amount": "9900"` 形态。覆盖：订单/退款列表+详情、6 个 stats 端点。TS typings `number → string`；算术/展示处入口统一转 `Number`（`"9900"/100` 隐式 coercion 能跑但别依赖）；`formatAmount` 类工具适配。
2. **lifecycle timeline 组件重写渲染模型**：平表 union（`logType`/`returnCode`/`targetType`… 18 字段两组互斥）→ payment 语义 9 字段：`id`、`source`（token 值 `GATEWAY`/`OPERATION`，不再是 `PAYMENT_LOG`/`OPERATION_LOG`）、`createdAt`、`action`、`actionName`、`outcome`、`performer`、`performerSystem`、`detail`。响应**无 orderNo 包装**（实返扁平事件数组，orderNo 走路径参数）。按 `actionName`+`outcome`+`performer` 渲染比旧平表更省事。
3. **status-distribution**：扁平 `refundPendingAuditCount` → 嵌套 `refundBacklog{ pendingCount, pendingAmount }`（**新增积压金额可用**）；分桶 `count`/`amount` 同为 string 形态。
4. **refund 列表/详情**：删 `auditorId`/`auditedAt`（后端 ghost 移除，此前也恒 null）；**query 筛选 `auditorId` 保留**（payment 支持）。不新增字段（`approvedAt`/`auditAgreed`/`auditRemark` 等）——第一轮接入零加戏，展现需求联调通过后从 UI 起单独提。
5. **比率字段不变**：`successRate`/`refundRate`/`approvalRate`/`avgAuditDurationMinutes`/`avgExecutionTimeMs` 保持 `BigDecimal`（JSON number）。
